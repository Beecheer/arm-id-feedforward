# 共享逆动力学模型

前馈使用 `tau = Y(q, dq, ddq) theta`。`Y` 为每个采样点七行、91 列的回归矩阵：
前 70 列是 Pinocchio 的七个连杆惯性参数列，其后依次为七轴粘性摩擦、
库仑摩擦、转子惯量列。行按“J1 的全部采样、J2 的全部采样、……”排列。
上位机控制入口直接用 Pinocchio 计算这套矩阵；测试验证它与辨识时
FIGAROH 的矩阵在相同状态下逐项一致。

URDF 的关节轴、关节原点和惯性字段保留自原模型。公开版仅更换可视和碰撞
几何，因此原来识别出的 91 个系数仍可与相同的 `Y` 相乘。文件哈希已改为
公开版 URDF 的哈希；参数来源中另留原 URDF 哈希供核对。

辨识的 91 维向量是能预测关节力矩的共享系数，不保证每个单独连杆惯性项
都是唯一或物理可行的真实值。运行时前馈由目标轨迹求值；实际反馈位置、
速度和力矩用于采集与事后误差分析。只有重力对照时令 `dq=ddq=0`，使用
同一套参数计算重力项。
